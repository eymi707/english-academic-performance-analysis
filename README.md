# English Academic Performance Analytics

## Project Overview
This project analyzes the Fall and Spring Semester grades from IEP students' to identify performance trends, areas of classwork/test/project performance for academic support.

## Stakeholder

Special Education Department Coordinator

## Business Question

Based on the Fall and Spring semester performance trends and results, what areas of English assignments should be prioritized for academic support?
